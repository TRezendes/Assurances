Get Assurances

by 232 Software

Assurances is a simple web app that plays audio files at the press of a button. It is called Assurances because it was created to share short verbal affirmations with someone you love. Just record yourself speaking, drop the audio files in the appropriate folder, and your special someone can hear your voice whenever they need a little reassurance.

Assurances does not include its own authentication system. If you want to keep your implementation private, you will need to implement one. This implementation of Assurances is secured using mTLS. Only the intended recipient can access the live app. Anyone without an authorized certificate lands on this page instead. For more on setting up mTLS, I recommend Mastering Mutual TLS (mTLS) with Nginx: A Deep Dive by José Manuel Requena Plens. It was the guide that finally helped me get mTLS up and running after weeks of struggling to get it to work right.

Assurances was lovingly written by hand, by a human, using CSS, Flask, HTML, and Javascript in Panic's Nova text editor. You can find out more about using Assurances and get the code at its GitHub repository.
